# RASA | Indian Kitchen & Bar — Website package

## What you get

- `index.html` — all website sections and page structure.
- `styles.css` — responsive layouts, dark brown/gold theme, arch and opening doors.
- `script.js` — live gold-particle Ganesha/RASA sequence, zoom transition, menu filtering, gallery, mobile navigation, enquiry form.
- `assets/rasa-mark.svg` — **recreated** vector interpretation of the mark visible in the supplied door-sticker screenshot. Swap for your official original SVG/PNG if you have one.
- `assets/favicon.svg` — matching browser icon.
- `assets/photo-fallback.svg` — graceful fallback when sample images cannot load.
- `index-standalone.html` — **single-file edition** of the same website for copy/pasting as just `index.html` (CSS, JS, logos included). Food/venue photos and Google Fonts still need internet.

## Easiest publishing method — GitHub Pages

1. Download `index-standalone.html` and rename it to **`index.html`**.
2. Upload that single file to the root of a GitHub repository.
3. On GitHub, open **Settings > Pages > Deploy from a branch > main > / (root) > Save**.
4. Open the GitHub Pages URL after deployment.

Alternatively, upload the **entire project folder contents** (`index.html`, `styles.css`, `script.js`, and `assets/`) into a GitHub repo. Keep the file names and folder structure as provided. In this case `index-standalone.html` is optional.

## IMPORTANT — fill in before making the website public

At the top of `script.js`, edit `RASA_CONFIG`:

```js
const RASA_CONFIG = {
  whatsappNumber: '', // REAL WhatsApp number, with country code and no +
  bookingEmail: '',    // REAL booking email; optional if WhatsApp set
  phoneNumber: '',
  googleMapsUrl: '',
  instagramUrl: '',
  replayIntroOnEveryVisit: true
};
```

If you use the **standalone** edition, find and edit the same `RASA_CONFIG` directly inside that HTML file.

**Reservations:** The form composes a WhatsApp message or email to your real restaurant contact. It does not store reservations or send automatic booking confirmations. With neither WhatsApp nor email configured, it clearly tells guests that enquiries are not yet connected. For instant real reservations or online card payments, you need a booking/payment integration and suitable back end.

**Images:** Food, chefs and interiors in this sample are illustrative Unsplash images linked over HTTPS, not actual photos of RASA. Replace them with RASA's own photographs when ready. Review permission/licensing and attribution for anything used commercially. The gallery explicitly identifies the photos as illustrative.

**Menu:** The displayed 6 dishes are example items, **not a verified official RASA menu**. Replace dishes, descriptions, photos, allergens and any prices with your approved offerings before publishing.

**Opening hours:** Copied from the provided design: Mon–Sat 12:00–00:00; Sunday 12:00–22:00. Confirm current hours before publishing.

**Address and links:** No restaurant address, phone, website/domain or actual reservation endpoint could be verified from the provided share link. They are intentionally omitted instead of being fabricated.

## Preview / controls

- Loading `index.html` shows the opening arch door. Click the door to open it, see the particle logo, then zoom into the website.
- Click **SKIP INTRO** to go directly inside.
- Add `?preview=1` to the URL to bypass the entrance while editing, e.g. `https://username.github.io/rasa/?preview=1`.
- On phones, the menu collapses and a fixed bottom navigation dock appears.
- Click a menu category to filter visible dishes.
- Click ambience photos to open/close the lightbox.
- If visitors prefer reduced motion, the animated intro is skipped after clicking enter.

## Customize brand colours

At the top of `styles.css` (or the inline `<style>` in the standalone version), edit `--ink`, `--brown`, `--gold`, `--cream`.

## Browser support

Designed for modern Chrome, Safari, Edge and Firefox. No front-end libraries and no server-side runtime required. Google Fonts and sample Unsplash photographs use remote URLs. Canvas particles are generated by JavaScript.
