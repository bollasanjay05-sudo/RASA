## Uploading to GitHub Pages

**One file:** use `index-standalone.html`, rename it `index.html` in your repository root. The local artwork, gate panels, CSS and JavaScript are embedded.

**Separate files:** upload `index.html`, `styles.css`, `script.js`, `favicon.ico`, `site.webmanifest`, and the complete `assets` folder while preserving paths.

The photos in the food and ambience sections are sample photography, not RASA venue imagery. The WhatsApp booking form is intentionally removed. Edit the contact links in the `RASA_CONFIG` section of `script.js`.
